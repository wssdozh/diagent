# Agent Environments

Настройки и пресеты под различные агентные среды:

- `dsh/` — DeepSeek Harness:
  - `presets/for-you/` — автономный пресет инженера с экономией токенов и сжатым Plan Mode.
  - `profiles/web/` — шаблон безопасного `cordis.patch.yml` без утечки секретов.
- `claude/` — шаблоны `CLAUDE.md` для Claude Code.
- `cursor/` — шаблоны `.cursorrules` для редакторов на базе Cursor / Windsurf.
