# diagent

Универсальный репозиторий конфигураций, пресетов, навыков и инструментов для автономных ИИ-агентов (DeepSeek Harness, Claude Code, Cursor, Codex).

Назван в честь Диогена Синопского: минимализм в архитектуре, высокий сигнал без «шелухи», экономия контекста и беспощадность к нейрослопу.

---

## Архитектура репозитория

```text
diagent/
├── agents/                     # Конфигурации под конкретные агентные среды
│   ├── dsh/                    # DeepSeek Harness
│   │   ├── presets/for-you/    # Пресет инженера (экономия токенов, сжатый Plan Mode)
│   │   └── profiles/web/       # Шаблон cordis.patch.yml без утечки секретов
│   ├── claude/                 # Шаблоны CLAUDE.md для Claude Code
│   └── cursor/                 # Шаблоны .cursorrules
│
├── skills/                     # Библиотека переиспользуемых навыков
│   ├── slopotron/              # Детектор и чистильщик русского нейрослопа и канцелярита
│   ├── laya-routing/           # Маршрутизация задач и оценка сложности через локальную модель
│   ├── fetchira/               # Маршрутизация веб-поиска, ридинга и headless-браузера
│   ├── subculture-chat/        # Неформальный тон без корпоративной фальши
│   ├── ip-as-logo/             # Генератор маскотов и простых персонажей
│   ├── shortform-pack/         # Генерация сценариев и тегов для Shorts/Reels/TikTok
│   └── catalog.json            # Каталог внешних и библиотечных навыков (без дублирования в git)
│
├── mcp/                        # Model Context Protocol: интеграции и локальные серверы
│   ├── registry.json           # Единый реестр серверов (TickTick, Fetchira, Laya, Linear)
│   └── laya/                   # Локальный классификатор задач (FastMCP, CPU-инференс)
│
├── prompts/                    # Промпты и защитные слои (guardrails)
│   ├── personas/               # Автономный инженер, ревьюер, аналитик
│   └── guardrails/             # Anti-slop, борьба с сикофантией, высокая плотность ответа
│
├── scripts/                    # Автоматизация окружения
│   └── sync.ps1                # Симлинковка навыков и регистрация пресетов в системе
│
├── .env.example                # Шаблон переменных окружения и API-ключей
├── .gitignore
├── LICENSE                     # MIT
└── README.md
```

## Быстрый старт

### 1. Клонирование и настройка окружения
```powershell
git clone https://github.com/USERNAME/diagent.git
cd diagent
Copy-Item .env.example .env
# Заполните необходимые ключи в .env (TickTick, API прокси, Linear и т.д.)
```

### 2. Синхронизация с системой
Для связывания навыков и пресетов с установленным DeepSeek Harness:
```powershell
.\scripts\sync.ps1
```
Флаги:
- `-DryRun` — показать запланированные действия без изменений в файловой системе.
- `-Force` — перезаписать существующие папки скиллов симлинками на репозиторий.

## Ключевые компоненты

### 1. Пресет `for-you` (DSH)
Заменяет стандартный пресет `standard`, снижая нагрузку на контекстное окно:
* **~1 265 токенов экономии** на каждом запросе за счет очистки ненужных JSON-схем инструментов (`workflow`, `tool-goal`).
* **~491 токен экономии** в режиме `/plan` (лаконичные правила вместо 6 абзацев).
* **Снижение расхода выходных токенов на 30–50%** благодаря встроенным ограничениям *Tone, Brevity, and Anti-Slop*.

### 2. Скилл `slopotron`
Специализированный инструмент для анализа русскоязычного текста:
* Выявляет и устраняет инфляторы («ключевой», «значительный»), фальшивую эмпатию («Надеюсь, было полезно!»), негативный параллелизм («не просто X, а Y») и парцелляцию.
* Поддерживает режимы `Fix` (исправление с сохранением логики) и `Detect` (выдача списка флагов).

### 3. Реестр MCP (`mcp/registry.json`)
Позволяет использовать одни и те же MCP-инструменты в DSH, Claude Desktop и Cursor:
* **TickTick**: управление задачами и списками через естественный язык.
* **Fetchira**: балансировщик поисковых квот, парсинг страниц и headless-браузер.
* **Linear**: синхронизация задач, циклов и PR.
* **Laya**: локальная классификация входящих задач без расхода платных API.

## Безопасность и публичный репозиторий

Репозиторий спроектирован для безопасной публикации:
* Файл `.env` и персональные токены добавлены в `.gitignore`.
* В шаблонах конфигураций используются переменные среды (`${VAR}` или `process.env.VAR`).
* Модели машинного обучения (`*.bin`, `*.safetensors`, `.venv`) исключены из трекинга git.
