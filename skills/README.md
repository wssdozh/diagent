# Skills Directory

Каталог специализированных навыков для агентов (DSH, Claude Code, Cursor и др.).

## Структура

1. **Авторские / локальные навыки** (в репозитории):
   - `slopotron/` — русскоязычный детектор и чистильщик нейрослопа, канцелярита и искусственных стилистических паттернов.
   - `laya-routing/` — локальная классификация задач и рекомендация моделей без платных API-запросов.
   - `fetchira/` — маршрутизация веб-поиска, глубокого ресёрча и чтения страниц через браузер.
   - `subculture-chat/` — неформальный тон общения без корпоративных штампов и сикофантии.
   - `ip-as-logo/` — генерация минималистичных маскотов и персонажей.
   - `shortform-pack/` — генерация сценариев и тегов для коротких видео (Reels / Shorts / TikTok).

2. **Внешние / библиотечные навыки**:
   - Описаны в `catalog.json` со ссылками на источники. Не засоряют репозиторий сторонним кодом.
   - Устанавливаются при необходимости через `scripts/sync.ps1`.
